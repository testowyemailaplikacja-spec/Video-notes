# Video Notes

Samodzielny program offline do transkrypcji nagrań OBS i tworzenia notatek, z docelowym zestawem funkcji konwertera plików Wiedora.

Rozwijany niezależnie od [Constant App](https://github.com/testowyemailaplikacja-spec/Constant_app). Po ukończeniu może zostać zintegrowany jako oddzielny moduł strony Wiedora.

Status: etap analizy i przeniesienia wzorca. Dokumentacja techniczna i kod konwertera źródłowego pochodzą z gałęzi `develop` Constant App; kopia wzorca nie jest gotową aplikacją Windows.
